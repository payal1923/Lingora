# Lingora

## Tagline
Speak English with Confidence.

## Project Description
Lingora is an AI-powered English learning application that helps users improve their English speaking skills through natural conversations with an AI tutor. The app provides real-time grammar correction, vocabulary suggestions, speaking practice, and personalized feedback to build confidence and fluency.

## Target Users
- Students
- Job Seekers
- Working Professionals
- Anyone learning English

## Main Goal
To make English speaking practice simple, interactive, and available anytime using AI.

## Version
Lingora v1.0
